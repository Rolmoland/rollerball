# 双核智能迷宫小球

本项目运行于 Infineon PSE84 双核开发板，使用 RT-Thread 完成 IMU 控制、双核通信、LVGL 迷宫显示及强化学习算法演示。

- **M33 核**：读取板载 IMU，判定倾斜方向，并通过 IPC 将方向与复位事件发送给 M55。
- **M55 核**：运行 LVGL、迷宫环境、人工演示采集、随机策略、Q-learning、DQN 和结果对比页面。

## 演示前准备

1. 确认 M33 与 M55 工程均已烧录并正常运行。
2. 打开 M55 的 FinSH/MSH 串口终端，地图和算法命令均在该终端执行。
3. 如需诊断 IMU 或手动发送复位事件，再打开 M33 的串口终端。
4. 每次加载新地图后，人工样本、随机策略统计、Q-learning 和 DQN 数据都会被清空，因此应按本文顺序完成一次完整演示。
5. 训练任务在后台执行。看到对应的 `train complete` 或 `complete` 日志后，再执行下一条命令。

## 完整功能演示

### 1. 获取并确认当前虚拟地图

在 M55 终端执行：

```text
map_show
```

终端会输出当前地图版本、最短路径长度，以及两条可再次加载的 `map_rows` 命令。地图编码含义如下：

| 数值 | 含义 |
| --- | --- |
| `0` | 可通行区域 |
| `1` | 墙 |
| `2` | 起点，整张地图必须恰好一个 |
| `3` | 终点，整张地图必须恰好一个 |

如需使用外部 AI 生成随机地图，将本文末尾的提示词发给 AI，然后把 AI 返回的两行命令依次粘贴到 M55 终端。例如：

```text
map_rows 0 2000000000,1111110111,0000000000,0110111110,0000000000
map_rows 5 0111111110,0000000000,0111011100,0000000003,0111111110
```

第二条命令执行后，开发板会自动校验并启用地图。成功日志应包含：

```text
[MAP] accepted revision=... shortest_path=...
[MAP] Q table, DQN, random baseline, and demo data cleared
```

再次执行 `map_show`，确认屏幕和终端显示的地图与 AI 返回内容一致。若第一段已经输入，但决定放弃本次加载，可执行 `map_abort`。

### 2. 人工控制迷宫

在 M55 终端执行：

```text
maze_mode demo
```

拿起开发板，通过前、后、左、右倾斜控制小球。每次倾斜触发一步，回正后再进行下一次倾斜，直至小球到达终点。

人工操作过程中，M55 会实时打印 `DEMO_DATA`，并将轨迹暂存在 RAM 中。完成后执行：

```text
demo_stats
```

验收标准：

- 小球按倾斜方向逐格移动，不能穿墙。
- 到达终点后，屏幕出现完成提示。
- `demo_stats` 的样本数大于 `0`，并且最近一条样本的 `done=1`。

需要重新进行人工演示时，可先在 M33 终端执行 `maze_reset` 将小球送回起点。`demo_clear` 会清空全部人工样本，仅在确实需要重新采集时使用。

### 3. 测试随机策略

在 M55 终端依次执行：

```text
random_reset
random_run 100
```

等待出现以下完成日志：

```text
[RANDOM] complete episodes=100 success=...
```

然后查看统计：

```text
random_stats
```

其中 `avg_success_steps` 表示成功回合的平均步数，不包含失败回合；`best_steps` 表示成功回合中的最少步数。

### 4. 测试 Q-learning

在 M55 终端依次执行：

```text
q_reset
q_train 500
```

等待出现：

```text
[Q] train complete episodes=500 success=...
```

再执行推理和统计：

```text
q_infer
q_stats
```

验收时确认屏幕上的小球能够沿学习到的路径移动，并检查终端结果：

```text
[Q] infer success=1 steps=... reward_x10=...
```

若推理失败，可继续执行 `q_train 500` 增加训练量，再次执行 `q_infer`。继续训练前不要执行 `q_reset`，否则已有 Q 表会被清空。

> `q_pretrain` 仅支持项目内置的默认地图，不支持通过 `map_rows` 加载的随机地图。演示随机地图时直接使用 `q_train`。若测试默认地图，可先完成人工演示，再执行 `q_pretrain` 和 `q_train 500`。

### 5. 测试 DQN

在 M55 终端依次执行：

```text
dqn_reset
dqn_train 1000
```

等待出现：

```text
[DQN] train complete episodes=1000 success=...
```

再执行推理和统计：

```text
dqn_infer
dqn_stats
```

验收时确认屏幕上的小球能够沿神经网络给出的路径移动，并检查终端结果：

```text
[DQN] infer success=1 steps=... reward_x10=...
```

若推理失败，可继续执行 `dqn_train 1000` 后再次推理。继续训练前不要执行 `dqn_reset`，否则网络、经验回放和统计数据都会被清空。

### 6. 查看最终对比

确认人工演示、随机策略、Q-learning 推理和 DQN 推理均已完成后，在 M55 终端执行：

```text
maze_mode compare
```

屏幕对比页会显示：

- **随机策略**：成功回合数及成功回合平均步数。
- **人工**：最近一次完整人工轨迹的步数。
- **Q-learning**：最近一次推理结果、步数及其与人工步数的差距。
- **DQN**：最近一次推理结果、步数及其与人工步数的差距。

若某项显示 `--`，说明该阶段尚未产生有效结果；若显示“失败”，说明最近一次对应推理未到达终点。

## 外部 AI 地图生成提示词

将以下内容完整发送给外部 AI：

```text
请为一个嵌入式设备上的迷宫强化学习演示生成一张 10x10 随机地图。

地图规则：
1. 地图固定为 10 行、10 列。
2. 每个格子只能使用数字 0、1、2、3。
3. 0 表示可通行区域，1 表示墙，2 表示起点，3 表示终点。
4. 整张地图必须恰好包含一个起点 2 和一个终点 3。
5. 起点到终点必须存在至少一条由上下左右移动组成的可达路径，不允许斜向移动。
6. 地图应具有适中的迷宫复杂度，包含转弯和分支，但不要只有唯一的一条狭长通道，也不要生成大面积完全开放区域。
7. 请自行检查行列数、字符合法性、起点和终点数量以及连通性。

输出规则：
1. 最终只能输出下面格式的两行命令，不要解释、序号、Markdown 代码块、引号或其他内容。
2. 每个 row 必须正好包含 10 个数字。
3. 每条命令包含连续 5 行地图，行与行之间只用英文逗号分隔，数字之间不能有空格。
4. 第一条命令必须从 map_rows 0 开始，第二条命令必须从 map_rows 5 开始。

严格输出格式：
map_rows 0 row0,row1,row2,row3,row4
map_rows 5 row5,row6,row7,row8,row9
```

## 常用辅助命令

### M55 终端

| 命令 | 作用 |
| --- | --- |
| `map_show` | 输出当前地图及可复用的加载命令 |
| `map_abort` | 放弃尚未完成的地图加载 |
| `demo_stats` | 查看人工轨迹采集统计 |
| `demo_clear` | 清空人工轨迹 |
| `random_stats` | 查看随机策略统计 |
| `q_stats` | 查看 Q-learning 状态 |
| `dqn_stats` | 查看 DQN 状态 |
| `maze_mode compare` | 打开最终策略对比页 |

### M33 终端

| 命令 | 作用 |
| --- | --- |
| `imu_print` | 打印当前加速度计和陀螺仪数据 |
| `gesture_print` | 打印当前倾斜方向判定 |
| `maze_reset` | 向 M55 发送迷宫复位事件 |
| `maze_print` | 查看当前复位事件编号 |
